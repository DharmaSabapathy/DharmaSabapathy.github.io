# Résumé

Put your résumé here as **`resume.pdf`** — that exact filename.

Five pages link to `assets/resume/resume.pdf`; keeping the name stable means
you can drop in a new version any time without touching the HTML.

Two habits worth keeping:

- Re-export rather than renaming. `resume.pdf` in the URL looks deliberate;
  `Resume_v7_FINAL_updated.pdf` does not.
- Update "Last updated: Month 20XX" in `resume/index.html` when you replace it.
